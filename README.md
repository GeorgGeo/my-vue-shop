# 🛒 Интернет-магазин кроссовок

Учебный проект интернет-магазина, разработанный на **Vue 3**.  
Реализован каталог товаров с корзиной, избранным, поиском, фильтрацией и оплатой.

---

## ⚙️ Стек технологий

- **Vue 3** — основа приложения  
- **Composition API / Options API** — разные подходы к написанию компонентов  
- **Vue Router** — маршрутизация между страницами  
- **TailwindCSS** — стилизация и адаптивный дизайн  
- **Axios** — работа с API  
- **@formkit/auto-animate** — анимации при добавлении/удалении элементов  
- **Vue Toastification** — уведомления  
- **ESLint + Prettier** — линтинг и форматирование кода  

---

## 🚀 Функционал

- 🔍 Поиск по товарам  
- 🏷️ Фильтрация по названию и цене  
- ❤️ Добавление товаров в избранное  
- 🛒 Добавление товаров в корзину  
- 💳 Оплата товара (компонент `PayByCard.vue`)  
- ✨ Плавные анимации при изменении списка товаров  

---

## 📂 Структура проекта

- `components/` — переиспользуемые компоненты (карточка товара, корзина, избранное и т. д.)  
- `pages/` — страницы (главная, избранное, корзина)  
- `App.vue` — корневой компонент приложения
